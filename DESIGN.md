# Evolve visual design system

Source: David’s visual specifications in the September 20 conversation. No pre-existing DESIGN.md was present when this reference was created.

- Canvas: warm porcelain #F8F7F4.
- Primary surface: white, 24px radius, #E5E2DC hairline border, diffuse spruce shadow.
- Secondary surface: linen #F2EFE9, 16px radius.
- Ink: spruce #0F282A; muted supporting text #5F706D.
- Display headings: Newsreader; UI: Plus Jakarta Sans; numeric values: JetBrains Mono and tabular numerals.
- Status chip text/background: Pending #92400E / #FFFBEB; Paid #166534 / #ECFDF5; Canceled #9F1239 / #FFF1F2. Dark text tones meet 4.5:1 minimum contrast; original brighter accent tokens remain available for non-text accents.
- Plus and focus accent: violet #8A38F5.
- Buttons and menu items: at least 44px target, 12px radius.
- Completed lifecycle stages: SVG checkmark; unverified processing stages stay estimates.
- Financial waterfall remains open. Existing math and selector-scoped keyboard interaction are unchanged.
- Fonts are bundled locally through Fontsource variable-font packages.
